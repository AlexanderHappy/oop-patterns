Задача: Система уведомлений
Контекст: Вам нужно создать систему отправки уведомлений, которая может использовать разные каналы связи в зависимости от типа уведомления, настроек пользователя или доступности сервисов.
Требования:
1. Создайте интерфейс стратегии NotificationStrategyInterface с методами:

send(string $recipient, string $message): array - отправка уведомления
getChannelName(): string - название канала
isAvailable(): bool - проверка доступности канала
getDeliveryTime(): int - примерное время доставки в секундах

2. Реализуйте конкретные стратегии:

EmailNotificationStrategy - отправка email (время доставки: 30 сек, комиссия за отправку)
SmsNotificationStrategy - отправка SMS (время доставки: 5 сек, ограничение по длине сообщения)
PushNotificationStrategy - push-уведомления (время доставки: 1 сек, требует активное устройство)
TelegramNotificationStrategy - через Telegram бота (время доставки: 3 сек, требует chat_id)

3. Создайте контекст NotificationManager с методами:

setStrategy() - установка стратегии
sendNotification() - отправка уведомления
getAvailableChannels() - получение доступных каналов
sendToMultipleChannels() - отправка через несколько каналов

4. Дополнительные требования:

Консольная команда для тестирования отправки
HTTP контроллер с API для отправки уведомлений
Service Provider для регистрации стратегий
Каждая стратегия должна возвращать результат с информацией о статусе, времени отправки, стоимости

5. Бонусные фичи:

Приоритетная отправка (если основной канал недоступен, использовать резервный)
Логирование всех отправленных уведомлений
Валидация получателей для каждого типа канала

Примеры использования:
bash# Консольная команда
php artisan notification:send "user@example.com" "Hello World" email
php artisan notification:send "+7900123456" "Test SMS" sms
json// API запрос
POST /notifications/send
{
    "recipient": "user@example.com",
    "message": "Your order is ready!",
    "channel": "email",
    "priority": "high"
}
